# Tugas 1 Mobile Programming

Latihan dasar Dart buat materi minggu 2.

Semua latihannya digabung di satu file `main.dart`, hasil jalaninnya ditaruh di
`output.txt`.

Isinya variabel, tipe data, const sama final, var sama dynamic, string, boolean,
operator, if else, switch, ternary, null safety, list, perulangan, terus fungsi.

Jalanin pake Dart SDK:

```bash
dart run main.dart
```
